# Docs homepage

- Scope: replace the Vite starter at `docs-site/src/App.tsx` with one Persuade-first product and documentation homepage.
- Audience/job: individual developers and engineering teams should understand Agent Factory, install it, see the complete shaping and delivery lifecycles, and choose `shape-work` or `do-work`.
- Proof: repository-backed lifecycle steps, three-host portability, bounded specialist roles, verification gates, and the explicit human merge/deploy boundary.
- Direction: approved comp `.impeccable/mocks/drawcord-b-vertical-loom.png`; The Drawcord System uses matte black textile, graphite stitching, and gold routed cords. The memorable moment is a vertical orchestration loom that gathers three hosts through specialist agents, human approval, and verification into a ready change.
- Constraints: install first; preserve React/TypeScript/Vite; no generic AI motifs or invented commercial proof; keyboard/touch/reduced-motion support; responsive layout without losing any flow step.
